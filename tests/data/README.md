# Test fixtures: provenance

All fixtures here are public or synthetic. None contains patient data. Sample names such as
`EBF0-0001` are test labels only.

| Path | Origin |
| --- | --- |
| `EBF0-0001.classified.fastq.gz` | 100 SARS-CoV-2 Illumina reads (read names `ERR5069949.*`, i.e. public ENA run ERR5069949) from the [nf-core test-datasets](https://github.com/nf-core/test-datasets) `sarscov2` set, with ` kraken:taxid\|2697049` appended to each read name to mimic Kraken2 `--classified-out` output. The file name is a test label. It is the Kraken2 `--classified-out` output of the TAXONOMY subworkflow test (nf-core `sarscov2` Kraken2 test DB on `test_1.fastq.gz`), all 100 reads classified. |
| `classified_small.fastq` | Synthetic, hand-written 2-read FASTQ for `bin/tag_reads_taxid.py` (the second quality line deliberately starts with `@`). |
| `S1_kraken2ID_PFP.fasta` | Contig `LGJG01000037` from the public ABRicate test assembly (`test/assembly.fa` in [tseemann/abricate](https://github.com/tseemann/abricate)), with read-style headers `>readN_kraken:taxid\|<taxid>`. |
| `S0_kraken2ID_PFP.fasta` | Intentionally empty (a sample with no classified reads). |
| `abricate_S1.csv` | Synthetic ABRicate `--csv` table (one hit, gene `patB`) for `bin/merge_abricate.py`. Field values are invented. |
| `abricate_S2_empty.csv` | Synthetic ABRicate `--csv` output with a header and no hits. |
| `abricate_db/card/` | Tiny single-entry ABRicate database (`tiny_card~~~tinyARG`), whose sequence is an excerpt of the `LGJG01000037` contig above. Built with `abricate --setupdb` in `quay.io/biocontainers/abricate:1.0.1--ha8f3691_1`. **Regenerate it if the ABRicate image is bumped** (the BLAST index version can change). |
| `bracken_combined.txt`, `kraken_combined.txt` | Synthetic KrakenTools `combine_kreports` / `combine_bracken_outputs`-style tables for two samples (`S1`, `S2`) for `ARRANGE_REPORTS` tests. Numbers are invented. |
| `metadata_test.csv` | Synthetic MERIDIAN metadata (`sample`, `sample_type`, `ID`) for `bin/make_meridian_config.py` tests. |
| `taxdump/` (`nodes.dmp`, `names.dmp`) | Synthetic minimal NCBI-style taxdump generated by [`tests/make_test_taxdump.py`](../make_test_taxdump.py) from a Kraken2 report (SARS-CoV-2 lineage plus *Homo sapiens*). The source report is a Kraken2 report from the public `sarscov2` test data (with a `9606` stub added); no real samples were used. Not a real NCBI release. |
| `db_dir/` | Synthetic, near-empty database folder with the layout written by `--build_databases` (`kraken2_pluspf_20250402/`, `taxdump_2025-04/`, `hostile/`, `abricate/`, `database_manifest.tsv`), for the `--db_dir` resolution tests. Files contain the word `fixture`; the checksums in the manifest are invented. |

The `-profile test` samplesheet ([`assets/samplesheet_test.csv`](../../assets/samplesheet_test.csv))
points at the public nf-core `sarscov2` `test_1.fastq.gz`, and `conf/test.config` uses the nf-core
`sarscov2` Kraken2/Bracken test database and the nf-core human `genome.fasta`; none of these is stored
in this repository.
